# TaskPulse 🗓️

**TaskPulse** is a task management application designed to help users manage and track their tasks efficiently. It includes functionalities such as adding, viewing, editing, deleting tasks, and sending daily reminders via email for tasks that are due soon.

## 🚀 Features

- **Task Management:** Add, view, edit, and delete tasks.
- **Daily Reminders:** Receive daily email reminders of tasks that are due soon.
- **Task Prioritization:** Assign priority levels to tasks.
- **Task Completion:** Mark tasks as completed.
- **Persistence:** Store tasks in a `tasks.json` file for persistence.
- **User-friendly Interface:** Simple and easy-to-use interface for task management.

## 🛠️ Technologies Used

- Python for functionality
- `smtplib` for sending emails
- `schedule` for task automation
- `dotenv` for managing environment variables
- JSON for task storage
- PythonAnywhere for automating daily mails
